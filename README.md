# RULESET

1인칭 1~10인 멀티플레이 공포게임 기획. 가제 **RULESET**.

플레이어는 규칙을 모르는 공간에 들어가, 죽어가며 규칙을 알아내고, 알아낸 규칙의 수만큼 돈을 받고 나온다. 공포의 정체는 괴물이 아니라 **내가 아직 모르는 규칙**이다.

## 핵심 원칙

1. **지식이 유일한 진짜 장비다** — 아이템은 시간을 벌어줄 뿐 상황을 해결하지 못한다
2. **모든 죽음은 사후에 설명 가능해야 한다** — 모든 규칙은 발동 0.8~3초 전에 고유한 신호를 낸다
3. **반복은 처벌된다** — 같은 수단으로 같은 존재를 세 번 밀어낼 수는 없다. 면역이 붙는다
4. **장비는 해결책이 아니라 거래다** — 모든 아이템은 기능 1개와 명확한 대가 1~2개를 갖는다
5. **규칙은 쌓이고 서로 충돌한다** — 라운드가 진행될수록 규칙 집합은 양립 불가능에 가까워진다
6. **정보는 플레이어 사이에 비대칭이어야 한다** — 규칙서를 읽은 사람만 그 규칙을 안다
7. **랜덤은 조합에만, 판정에는 없다** — 규칙이 발동하는 판정 자체는 100% 결정론적이다

## 수치 요약

- 규칙 **707개** = 공통 416 + 맵 전용 **250** + 가변 통로 9 + 교차 32 — 감사에서 23개 삭제·47개 수정, 기계화에서 4개 삭제·1개 분리, 합계표 드리프트 12개 정정
- 맵 **12종 중 가용 11종, 전부 층 구성 완비** — 수영장만 v1 보류. 선박은 `ship.tilt`를 이산 단계값으로 두면 전용 시스템이 필요 없다
- 구역 총 **198개** (극장 12 ~ 연구소 25), 칠판 48개, 정식 은신처 맵당 6개 고정
- 맵 12종, 맵당 전용 규칙 12\~32개 + **전용 개체 2종**(총 24종)
- 티어 구성 T1 15% / T2 33% / T3 37% / T4 15%
- 처벌 비중 즉사 24% / 지연사 21% / 표식 16% / 소환 15% / 징수 13% / 연쇄 11%
- 한 게임 활성 규칙 = 라운드 곡선 × 인원 계수. **인원은 태그 계층에만 곱한다** — 1인 20\~63 / 4인 20\~100 / 10인 29\~127
- **진짜 상한은 「한 방 24개」다.** 100은 전역 상한이 아니라 4인의 천장이었다. 한 방 7\~24개
- 구역 태그 30종, 경고 신호 **54조합**(위치 3 × 질감 6 × 패턴 3)
- 위치 = 귓가 0.18m(몸) / 손 0.45m(행위) / 광원 3.0m(세계). 방향이 아니라 **거리**로 가른다
- 신호 청취 반경 **15m**(근접 음성과 동일), 타인 신호 -8dB, 동시 상한 3개
- 유예 = max(**하한(티어)**, (티어 기본 + 처벌 보정) × 라운드 계수)
- 기본 T1 3.0 / T2 2.4 / T3 2.0 / T4 1.2초 — 하한 T1 1.8 / T2 1.5 / T3 1.3 / T4 1.2초
- 신호 길이 ≤ 유예 × 0.6, 식별 특징은 첫 0.3초 안
- 폐활량 100 — 달리기 -8/초, 숨 참기 -12/초, 회복 +6/초
- 규칙은 **매 라운드 새로 뽑는다.** 수첩도 라운드 단위로 비워진다
- 수첩에 **장수 제한 없음**. 수입의 상한은 페이지가 아니라 시계가 만든다
- 정산 = **밖으로 나온 수첩들 + 칠판**의 합집합, 라운드마다 전액. 전멸 0
- 칠판 = 층마다 1개. 기록 4초 / 읽기 2초 / **지우기 불가**
- 인당 수입 3인 5.0 / 10인 3.5 — 대규모 파티는 안전을 사고 수입을 내준다

## 다음 작업

**판정 조건 기계화가 끝났다.** 707개 전부가 조건식으로 내려갔고(`판정.md`), 문법이 확정됐다(`판정언어.md`). JSON을 막던 것은 이제 없다.

1. **충돌 태그 데이터화** — 비고란에 산문으로만 적혀 있다. 조건식이 생겼으므로 **식에서 기계적으로 추출할 수 있다** — 같은 필드를 읽는 규칙끼리 묶으면 그것이 곧 충돌 태그다. 기계화 전이었다면 손으로 해야 했던 일이다
2. **JSON 스키마 확정과 변환** — `판정.md`의 블록이 그대로 레코드가 된다. `constraint` 다섯 값(금지·사실·무효·해제·설명), `trigger`(when·for·within·once), 그리고 신호의 이중 처리(본인=로컬 / 타인=월드 좌표)를 반영한다
3. **3라운드 연속 테스트** — 단발 라운드로는 측정이 안 되는 것이 하나 있다. **런이 누적될 때도 맥락만으로 같은 신호를 구분할 수 있는지**다. 1라운드에서는 「발밑·마른소리」가 세 번 울렸고 테스터는 한 번도 어느 규칙인지 되묻지 않았다 — 맥락이 구분을 대신했다. 규칙이 매 라운드 새로 뽑히므로 2라운드부터는 **기억 속의 규칙과 이번 판의 규칙이 어긋날 수 있다.** 여기서 맥락이 버티지 못하면 신호 유일성 제약의 적용 범위를 넓혀야 한다. 같은 테스트에서 **7라운드 이후 처벌 보정이 사라지는 것이 실제로 뭉개지는 느낌인지**도 확인한다
4. **종이 테스트 2라운드 (대면)** — 1라운드는 채팅·1인이라 가정 4개 중 3개만 측정됐다. 관문 기준(테스터 4인 2회 자발적 재도전)은 아직 미측정이다. 폐활량·자세·수첩·밀기·이모션을 카드에 반영한 뒤 대면으로 돌린다. **타인 신호 청취는 다인 플레이에서만 측정된다**
5. **기준 음원 12개** — 사양 확정됨. 기준 6종은 `경고신호.md`의 질감 음향 사양표를 맞추고, **고티어 축약본 6종**이 더 필요하다 — 패턴 「떨림」이 +250ms를 더하는데 T4 신호 길이 상한이 0.72초라 테일을 잘라야 한다

