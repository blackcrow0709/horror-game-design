# RULESET

1인칭 1~10인 멀티플레이 공포게임 기획. 가제 **RULESET**.

플레이어는 규칙을 모르는 공간에 들어가, 죽어가며 규칙을 알아내고, 알아낸 규칙의 수만큼 돈을 받고 나온다. 공포의 정체는 괴물이 아니라 **내가 아직 모르는 규칙**이다.

## 핵심 원칙

1. **지식이 유일한 진짜 장비다** — 아이템은 시간을 벌어줄 뿐 상황을 해결하지 못한다
2. **모든 죽음은 사후에 설명 가능해야 한다** — 모든 규칙은 발동 0.8~3초 전에 고유한 신호를 낸다
3. **반복은 처벌된다** — 같은 수단으로 같은 존재를 세 번 밀어낼 수는 없다. 면역이 붙는다
4. **장비는 해결책이 아니라 거래다** — 모든 아이템은 기능 1개와 명확한 대가 1~2개를 갖는다
5. **규칙은 쌓이고 서로 충돌한다** — 라운드가 진행될수록 규칙 집합은 양립 불가능에 가까워진다
6. **정보는 플레이어 사이에 비대칭이어야 한다** — 규칙서를 읽은 사람만 그 규칙을 안다
7. **랜덤은 조합에만, 판정에는 없다** — 규칙이 발동하는 판정 자체는 100% 결정론적이다

## 수치 요약

- 규칙 **578개** = 공통 425 + 맵 전용 112 + 가변 통로 9 + 교차 32
- 티어 구성 T1 15% / T2 33% / T3 37% / T4 15%
- 처벌 비중 즉사 24% / 지연사 21% / 표식 16% / 소환 15% / 징수 13% / 연쇄 11%
- 한 게임 활성 규칙 **15 + 인원 × 8**개 (4인 47, 10인 95), **한 방에서 걸리는 건 7~21개**
- 구역 태그 30종, 경고 신호 조합 46/48 사용
- 폐활량 100 — 달리기 -8/초, 숨 참기 -12/초, 회복 +6/초
- 규칙은 **매 라운드 새로 뽑는다.** 수첩도 라운드 단위로 비워진다
- 수첩에 **장수 제한 없음**. 수입의 상한은 페이지가 아니라 시계가 만든다
- 정산 = **밖으로 나온 수첩들 + 칠판**의 합집합, 라운드마다 전액. 전멸 0
- 칠판 = 층마다 1개. 기록 4초 / 읽기 2초 / **지우기 불가**
- 인당 수입 3인 5.0 / 10인 3.5 — 대규모 파티는 안전을 사고 수입을 내준다

## 다음 작업

순서대로 하는 게 맞다. 1번이 2번을 막고 있다.

1. **「신호를 누가 듣는가」 결정** — 지금 설계에 정의가 없다. 1라운드에서 동료의 위반에 신호가 울렸는데 플레이어가 막지 못해 죽었다. 신호가 플레이어 로컬인지 월드 좌표인지에 따라 데이터 구조가 달라지므로 **JSON보다 먼저 정해야 한다.** 유력안은 "전원이 듣되 위반자 쪽에서 들린다" — 위치 8종이 이미 공간 프리셋이라 구현 비용이 거의 없다
2. **JSON 스키마 확정** — 설계도의 필드 구조를 확정하고 578개를 데이터로 변환. `stance`/`seated` 분리와 지속시간 기반 트리거를 이때 반영한다
3. **3라운드 연속 테스트** — 단발 라운드로는 측정이 안 되는 것이 하나 있다. **런이 누적될 때도 맥락만으로 같은 신호를 구분할 수 있는지**다. 1라운드에서는 「발밑·마른소리」가 세 번 울렸고 테스터는 한 번도 어느 규칙인지 되묻지 않았다 — 맥락이 구분을 대신했다. 그런데 규칙이 매 라운드 새로 뽑히므로 2라운드부터는 **기억 속의 규칙과 이번 판의 규칙이 어긋날 수 있다.** 같은 신호가 다른 규칙일 때 맥락이 버티는지가 변주 9종의 필요 여부를 결정한다. 같은 테스트에서 재추첨 구조상 라운드 간 난이도 곡선이 규칙 수와 티어 비중만으로 결정되는지도 확인한다
4. **종이 테스트 2라운드 (대면)** — 1라운드는 채팅·1인이라 가정 4개 중 3개만 측정됐다. 관문 기준(테스터 4인 2회 자발적 재도전)은 아직 미측정이다. 폐활량·자세·수첩을 카드에 반영한 뒤 대면으로 돌린다
5. **기준 음원 6개** — 질감 6종. 위치는 공간 처리 프리셋 8종으로 독립 처리하므로 6×8을 따로 녹음할 필요 없다
